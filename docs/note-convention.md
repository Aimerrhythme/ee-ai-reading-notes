# 阅读周记规范

## 命名
- `notes/<YYYY>/<YYYY>-W<ww>-<slug>.md`，ISO 周号两位，如 `2026-W44`。
- 每周 1 条（可多条，slug 区分）。

## 模板

```markdown
# <YYYY>-W<ww> · <中文标题>

> 标签：#负荷预测 #深度学习 ｜ 阅读时长：约 5 分钟

## 本周读了什么
- 3–6 条要点（用自己的话转述）

## 课堂一句带过
> 「……」（一句话，适合在相关章节引入）

## 链接
1. [标题](URL) — 来源 / 年份
2. …（最多 3 个）

## 我的一点想法（可选）
```

## 要求
- 链接须为公开可访问的原始来源；不贴付费全文、不大段复制。
- 篇幅 ≤ 400 字（不含链接）。
- 与 `ee-ai-teaching-briefs` 已写主题可以重叠，但本仓只做阅读线索，不展开教学设计。

# ee-ai-reading-notes · 电气 × AI 阅读周记

每周一条短笔记：**本周读了什么 + 课堂上怎么一句带过 + 1–3 个链接**。

与 [`ee-ai-teaching-briefs`](https://github.com/Aimerrhythme/ee-ai-teaching-briefs) 的分工：
- `ee-ai-teaching-briefs`：作品级教辅短文，完整讲清一个主题；
- **本仓**：轻量周记，记录阅读线索，5 分钟能读完。

## 一条笔记 = 三件事
1. **本周读了什么**：论文 / 技术博客 / 标准 / 新闻，3–6 句要点
2. **课堂一句带过**：上课时可以怎么用一句话引入
3. **链接**：1–3 个原始来源

## 目录

```
notes/YYYY/YYYY-Www-<slug>.md   # 例：notes/2026/2026-W44-pv-forecast-transformer.md
docs/note-convention.md
themes.md   # 可选话题线索
INDEX.md
```

## 说明

- **中文为主**，必要处附英文术语。
- 本仓由定时自动化**持续追加**内容：每次从 `themes.md` 取一条 `todo` 主题 → 生成条目 → 更新 `INDEX.md` 与 `CHANGELOG.md` → 将主题标为 `done`。
- 定位为**教学材料**，**不代写**毕业设计 / 课程设计 / 论文。
- 许可：MIT（见 `LICENSE`，含教学声明）。
- 只摘要与转述，不大段复制原文；引用请指向原始链接。
